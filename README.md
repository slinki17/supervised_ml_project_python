# Felügyelt Gépi Tanulás Projekt
## Python (Jupyter) notebook egy felügyelt gépi tanulási projekthez Data Science eszközökkel és osztályozó módszerekkel.

A projekt fő célja a spotify.csv fájlban található legtöbbet streamelt dalok tempójának meghatározása (osztályozás) különböző zenei tulajdonságok alapján. A projekt a következő területeket érinti:

* Adatelőkészítés
* EDA statisztikák
* Osztályozás különböző módszerekkel (Decision Tree + Random Forest)
* Eredmények értelmezése/értékelése
* Eredmények ábrázolása

## Projekt fájlok

* supervised-ml-project.ipynb - A projektet tartalmazó Jupyter notebook
* spotify.csv - A dalok adatait tartalmazó Excel táblázat

## Projekt megtekintése/futtatása

Notebook betöltése Jupyter környezetben és a szükséges könyvtárak telepítése/betöltése
